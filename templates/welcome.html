它能做什么

触控板 单指滑动移动光标，轻点就是左键；双指上下滚动，双指捏合缩放，长按拖拽选中。
键盘与输入框 完整键盘布局，还有一条输入框——手机打好字自动上屏，中文拼音也不会打断。
语音输入 按住话筒说话，松手整段上屏。断句自动切分，中英混说也能认出专有名词。
Code 遥控 常用快捷键一键触发，改代码、切窗口、跑终端都不用把手从手机上挪开。

语音识别需要你自己的 API Key

Movo 的语音输入调用火山引擎「豆包语音识别」， 识别在云端完成、按你自己的账号额度计费。所以安装包里不会带任何密钥—— 填你自己的 Key，用多少算多少。

如何获取 API Key
  1. 登录 火山引擎控制台，进入「智能语音技术」。
  2. 开通 流式语音识别大模型（SAUC）。开通后权限生效可能要几分钟。
  3. 在 API Key 管理 里创建一个 Key 并复制，形如 x-x-x-x-x。
  4. 粘贴到下面，先点「测试连接」确认可用，再保存。

暂时不填也可以，语音会自动使用内置的离线模型（准确率低一些，中英混说容易出错）。
